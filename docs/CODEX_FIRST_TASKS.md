# Primeiras tarefas para o Codex no VS Code

Executar uma tarefa por vez.

## Tarefa 1 — Diagnóstico das fontes

- clonar HERO.Agenda, HERO.IA unificado e backend legado;
- identificar versões, branches e deploys;
- produzir mapa de reaproveitamento;
- não copiar arquivos ainda.

## Tarefa 2 — Scaffold local

- criar workspace para `extension` e `backend`;
- configurar package manager;
- adicionar lint, formatter, testes, typecheck e build;
- criar CI sem deploy.

## Tarefa 3 — Extensão mínima

- reutilizar apenas adapter DOM e inserção de texto;
- criar toolbar com três botões;
- botões abrem painéis vazios identificados;
- testar idempotência e troca de conversa.

## Tarefa 4 — Backend mínimo

- criar API modular;
- adicionar `/health`;
- validar configuração por ambiente;
- adicionar testes;
- não conectar produção.

## Tarefa 5 — Copiloto assistido

- criar contrato de análise;
- implementar prompt protegido e perfil genérico;
- inserir rascunho sem envio;
- guardar logs técnicos sem conversa completa por padrão.

## Tarefa 6 — Configuração

- criar formulário e schema;
- persistir em ambiente de desenvolvimento;
- adicionar segmento e instruções;
- validar isolamento multiempresa.

## Tarefa 7 — Agenda leitura

- implementar serviços e horários internos;
- motor determinístico local;
- somente depois integrar Google Calendar em leitura.

## Formato obrigatório do relatório de cada tarefa

```text
Fatos encontrados
Alterações realizadas
Arquivos alterados
Comandos executados
Resultados
Riscos
Pendências
Próxima menor etapa
```
